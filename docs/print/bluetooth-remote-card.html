Using the Remote 🤳

Hands-free photos — great for group shots!
ON/OFF switch
on the side
1
Turn it ON — flip the side switch before you start.
2
Get everyone in frame and smile!
3
Press the button to snap the photo.
4
When done, turn the switch OFF.
🙏 Please return the remote to the table when you're finished so the next guests can use it too!
Don't see the remote, or it's in use? No problem — just tap the big pink button on screen instead.
